# nicebodrum.com

Nice Bodrum (kapı motoru, bahçe kapısı) statik web sitesi. Hosting: Güzel Hosting (cPanel).

- Sayfalar: kök dizindeki `*.html` (temiz URL'ler `.htaccess` ile)
- Form: `gonder.php` (kütüphanesiz SMTP). **Depodaki dosyada şifre yer tutucudur.** Sunucudaki gerçek `gonder.php` üzerine bu dosyayı yüklemeyin.
- Control X Access sayfası: `control-x-access.html`, görseller `img/control-x/`
